# Decision Boundary Lab

A Python project for exploring decision boundaries, kernel methods, and model robustness in Support Vector Machines across synthetic datasets, label noise, augmentation, and high-dimensional settings.

## Project overview

The project includes:

- `01_simulate_data.py` — generates and saves the linear and circular synthetic datasets
- `02_perceptron_vs_svm.py` — compares a perceptron and a linear SVM on both datasets
- `03_svm_kernels.py` — evaluates RBF and polynomial kernels on the circular dataset
- `04_data_augmentation.py` — studies overfitting via noisy augmentation and threshold curves
- `05_label_noise.py` — analyzes robustness under shuffled/noisy labels
- `06_high_dimensionality.py` — examines how dimension affects SVM performance and robustness
- `utils.py` — shared utilities for loading data, plotting, and metric computation

Generated output folders:

- `data/` — saved `.npz` dataset files
- `figures/` — plots and summary figures generated by the experiments

## Requirements

Use Python 3.10+ and install dependencies:

```bash
pip install -r requirements.txt
```

## Run the project

From the project root:

```bash
python 01_simulate_data.py
python 02_perceptron_vs_svm.py
python 03_svm_kernels.py
python 04_data_augmentation.py
python 05_label_noise.py
python 06_high_dimensionality.py
```

Each script saves results in the `data/` and `figures/` folders.
